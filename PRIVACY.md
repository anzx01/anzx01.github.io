# Privacy

This is a static GitHub Pages site. It does not run a custom backend and does not intentionally collect passwords, payment details, or private account data.

## Third-Party Services

Depending on site configuration and page features, visitors may load scripts or assets from:

- GitHub Pages and GitHub APIs, for hosting and repository metadata.
- giscus, for comments backed by GitHub Discussions.
- Busuanzi, for page and site visit counters.
- CDN providers such as jsDelivr or cdnjs, for optional frontend libraries.
- Google Analytics or Google AdSense, only when IDs are configured in `_config.yml`.

These services may receive visitor IP address, browser metadata, referrer, requested URL, and other standard web request data. Their own privacy policies apply.

## Comments

When comments are enabled, comments are handled by the configured third-party provider. With the current giscus configuration, comments are stored in the configured GitHub Discussions repository and are subject to GitHub's terms and privacy policy.

## Local Storage

Some frontend scripts may use browser storage to cache presentation data, such as repository card thumbnail URLs. This data stays in the visitor's browser unless the browser or user clears it.

## Advertising And Analytics

Google Analytics and Google AdSense are disabled unless valid site-specific values are configured in `_config.yml`. Do not enable advertising or analytics without confirming the relevant service terms and updating this notice if needed.
